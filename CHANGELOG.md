## [1.0.0] - 2026-04-18

### Added
- Zero-backend Markdown-driven wiki application built with React 19, Vite 6, and Tailwind CSS 4.
- KaTeX LaTeX math support for inline `$ ... $` and block `$$ ... $$` math expressions.
- Native Mermaid.js diagram rendering for flowcharts, sequence diagrams, and architecture maps.
- Client-side instant full-text search indexing across titles, categories, tags, and content.
- Multilingual UI support (i18n) for English, Simplified Chinese, Traditional Chinese, Japanese, and Korean.
- One-click RSS 2.0 feed generator for site articles.
- Dynamic dark/light theme switching with persistent localStorage state.
- Automated SEO metadata, Open Graph headers, and JSON-LD structured data generation.
- One-click social sharing buttons for Twitter, Facebook, WhatsApp, Telegram, and copy link.
